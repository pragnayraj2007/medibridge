MediBridge Patient App (Expo SDK 57) — Windows

The app talks to the DEPLOYED backend by default (https://medibridge-api-rose.vercel.app,
set in app.config.js), so a phone only needs internet — no PC backend or same Wi-Fi.

First-time setup (inside this folder):
  1) npm install
  2) npx expo start -c        -> scan the QR code with Expo Go (Android)

Use a LOCAL backend instead (PC running uvicorn on port 8000, phone on the same Wi-Fi):
  PowerShell:  $env:EXPO_PUBLIC_API_URL="http://<your-PC-IP>:8000"; npx expo start -c

Checks:
  check-android.bat   -> dependency versions, resolved config, Android bundle build

Installable Android APK (no Play Store) — needs a free Expo account:
  npx eas-cli@latest login
  npx eas-cli@latest build -p android --profile preview
  -> open the download link/QR on the phone and install the APK
  (first run asks to create the EAS project; accept. Config is in eas.json.)

Web version (served at https://medibridge-xi.vercel.app/patient): export-web.bat
